# Pixel Pet 🐈‍⬛

A macOS desktop pet — a pixel-art black cat that walks across the bottom of
your screen on top of all windows. PyObjC/Cocoa + Pillow. No tkinter, pygame,
or Electron.

## Features
- Walks across the bottom of the screen with true per-pixel transparency
- **Left click** → sits for 3s, then walks again
- **Drag** → move the cat anywhere
- **Right click** → menu with *Quit Pixel Pet*
- Speech bubbles (sitting: `~meow meow`, `purrr...`, `nya~`, `(˘ω˘)` /
  walking every ~8s: `where my fish nya`, `i am speed ~`, `*sniff sniff*`,
  `zoomies!!`)

## Setup
```bash
brew install python@3.11
pip3.11 install Pillow pyobjc
python3.11 make_sprites.py     # generate placeholder sprites (already done)
```

## Run from source
```bash
python3.11 pet.py
```
Stop: right-click the cat → *Quit Pixel Pet*, `Ctrl+C`, or
`pkill -f pet.py; rm -f /tmp/pixel_pet.lock`.

## Build a .app
```bash
pip3.11 install py2app
python3.11 setup.py py2app
open dist/PixelPet.app
```
If macOS blocks it: `xattr -cr dist/PixelPet.app && open dist/PixelPet.app`

## Custom sprites
Replace `sprite_sheet/walk_sprite.png` and `sprite_sheet/sit_sprite.png` with
your own 512×128 sheets (4 frames of 128×128, cat facing left). White
backgrounds are auto-removed on load. The included sprites are programmatic
placeholders generated by `make_sprites.py` — swap in real ChatGPT/Canva
sprites any time.

Based on the *Desktop Pet — Pixel Cat* prompt by June Aekkaluk.
